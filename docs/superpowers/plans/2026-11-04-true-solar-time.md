# 国内出生地与真太阳时

**目标：** 在现有离线排盘中选择国内省市，保存出生地与原始钟表时间，按可关闭的真太阳时口径计算紫微盘和四柱命卦。

**取舍：** 复核已有紫微／八字开源项目，复用许可明确的地区数据，不替换现有排盘引擎。省市坐标是近似代表点，允许修改经度。不接入联网地图或定位。历史记录未带开关时保持原结果。

**时间约定：** 默认输入标准北京时间 UTC+8；可明确选择夏令钟表时 UTC+9 或新疆地方时 UTC+6，不根据地区猜测原始记录的时制。启用真太阳时须填准确时分。由实际 UTC 瞬间计算均时差，再加东经每度四分钟；跨日使用完整日期。年、月柱及冬夏令仍按实际瞬间与北京时间交节表比较，日、时柱及紫微生日按换算后的真太阳日期／时辰计算。该术数日期选择作为项目约定明确展示。

**范围：** model.ts、solar-time.ts、birth-regions.ts、输入／盘心／命卦／档案展示、保存校验、测试入口、许可、版本和使用说明；同一编译入口覆盖 PWA、Android、Windows、Mac。

## 重点边界

经度120°仍有均时差；不得提前取整造成换时辰。月底／年末／闰日正确进退日期；立春前后换算不改变物理交节顺序。出生时间不详不能伪造准确结果。旧档案不得自动开启校正；刷新、分组、隐藏生辰、主题与横屏不丢输入。来源含错位或父级回退坐标时不直接沿用。
